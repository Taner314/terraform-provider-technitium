# technitium_dns_record_app (Resource)

Manages an APP record, which hands queries for the name to an installed DNS app.

Records are matched by zone, name and type (one APP record per name).

## Example Usage

```terraform
# Split horizon: different answers for LAN and internet clients.
resource "technitium_app" "split" {
  name = "Split Horizon"
}

resource "technitium_dns_record_app" "www" {
  zone       = "example.com"
  name       = "www"
  app_name   = technitium_app.split.name
  class_path = "SplitHorizon.SimpleAddress"
  record_data = jsonencode({
    public  = ["203.0.113.10"]
    private = ["192.168.1.10"]
  })
}
```

## Schema

### Required

- `app_name` (String) Installed app name, e.g. `Split Horizon`.
- `class_path` (String) App class path, e.g. `SplitHorizon.SimpleAddress`.
- `name` (String) Record name relative to the zone; `@` for the zone apex.
- `zone` (String) Authoritative zone the record belongs to.

### Optional

- `comments` (String) Free-form comments stored with the record.
- `disabled` (Boolean) Whether the record is disabled (kept but not served).
- `expiry_ttl` (Number) Seconds after the last modification at which the server deletes the record; 0 disables expiry.
- `record_data` (String) App-specific record data (often JSON).
- `ttl` (Number) TTL in seconds. Defaults to the server's default record TTL. All records of one type at the same name form an RRset and share a single TTL, so give them the same value.

### Read-Only

- `fqdn` (String) Fully qualified domain name of the record.
- `id` (String) Record identifier and import ID: `<zone>/<name>`.
