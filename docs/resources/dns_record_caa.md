# technitium_dns_record_caa (Resource)

Manages a CAA (certification authority authorization) record.

Records are matched by zone, name and `flags`, `tag`, `value`.

## Example Usage

```terraform
resource "technitium_dns_record_caa" "le" {
  zone  = "example.com"
  name  = "@"
  flags = 0
  tag   = "issue"
  value = "letsencrypt.org"
}

resource "technitium_dns_record_caa" "iodef" {
  zone  = "example.com"
  name  = "@"
  flags = 0
  tag   = "iodef"
  value = "mailto:security@example.com"
}
```

## Schema

### Required

- `flags` (Number) Flags; 128 marks the property critical.
- `name` (String) Record name relative to the zone; `@` for the zone apex.
- `tag` (String) Property tag: `issue`, `issuewild` or `iodef`.
- `value` (String) Property value, e.g. `letsencrypt.org`.
- `zone` (String) Authoritative zone the record belongs to.

### Optional

- `comments` (String) Free-form comments stored with the record.
- `disabled` (Boolean) Whether the record is disabled (kept but not served).
- `expiry_ttl` (Number) Seconds after the last modification at which the server deletes the record; 0 disables expiry.
- `ttl` (Number) TTL in seconds. Defaults to the server's default record TTL. All records of one type at the same name form an RRset and share a single TTL, so give them the same value.

### Read-Only

- `fqdn` (String) Fully qualified domain name of the record.
- `id` (String) Record identifier and import ID: `<zone>/<name>/<flags> <tag> <value>`.

## Import

# <zone>/<name>/<flags> <tag> <value>
