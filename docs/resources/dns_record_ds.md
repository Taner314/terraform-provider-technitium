# technitium_dns_record_ds (Resource)

Manages a DS (delegation signer) record.

Records are matched by zone, name and `key_tag`, `algorithm`, `digest_type`, `digest`.

## Example Usage

```terraform
# DS for a signed child zone. With the child hosted on Technitium too, take
# the values from technitium_dns_zone_dnssec.ds_records.
resource "technitium_dns_record_ds" "sub" {
  zone        = "example.com"
  name        = "sub"
  key_tag     = 12345
  algorithm   = "ECDSAP256SHA256"
  digest_type = "SHA256"
  digest      = "BBE017B17E5CB5FFFF1EC2C7815367DF80D8E7EAEE4832D3ED192159D79B1EEB"
}
```

## Schema

### Required

- `algorithm` (String) DNSSEC algorithm, e.g. `ECDSAP256SHA256`.
- `digest` (String) Digest as a hex string.
- `digest_type` (String) Digest type, e.g. `SHA256`.
- `key_tag` (Number) Key tag of the referenced DNSKEY.
- `name` (String) Record name relative to the zone; `@` for the zone apex.
- `zone` (String) Authoritative zone the record belongs to.

### Optional

- `comments` (String) Free-form comments stored with the record.
- `disabled` (Boolean) Whether the record is disabled (kept but not served).
- `expiry_ttl` (Number) Seconds after the last modification at which the server deletes the record; 0 disables expiry.
- `ttl` (Number) TTL in seconds. Defaults to the server's default record TTL. All records of one type at the same name form an RRset and share a single TTL, so give them the same value.

### Read-Only

- `fqdn` (String) Fully qualified domain name of the record.
- `id` (String) Record identifier and import ID: `<zone>/<name>/<key_tag> <algorithm> <digest_type> <digest>`.
