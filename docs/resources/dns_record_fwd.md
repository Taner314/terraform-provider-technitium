# technitium_dns_record_fwd (Resource)

Manages an FWD record (Technitium-specific forwarder) in a conditional forwarder zone. The server ignores `ttl` for FWD records.

Records are matched by zone, name and `protocol`, `forwarder`.

## Example Usage

```terraform
resource "technitium_dns_record_fwd" "corp" {
  zone              = "corp.internal"
  name              = "@"
  protocol          = "Tls"
  forwarder         = "dns.corp.example"
  dnssec_validation = true
}
```

## Schema

### Required

- `forwarder` (String) Forwarder address, or `this-server`.
- `name` (String) Record name relative to the zone; `@` for the zone apex.
- `zone` (String) Authoritative zone the record belongs to.

### Optional

- `comments` (String) Free-form comments stored with the record.
- `disabled` (Boolean) Whether the record is disabled (kept but not served).
- `dnssec_validation` (Boolean) Validate DNSSEC for forwarded responses.
- `expiry_ttl` (Number) Seconds after the last modification at which the server deletes the record; 0 disables expiry.
- `priority` (Number) Priority; lower values are queried first, equal priorities concurrently.
- `protocol` (String) Transport: `Udp`, `Tcp`, `Tls`, `Https` or `Quic`.
- `proxy_address` (String) Proxy address when `proxy_type` is `Http` or `Socks5`.
- `proxy_password` (String, Sensitive) Proxy password. Not readable from the server, so changes made outside Terraform are not detected.
- `proxy_port` (Number) Proxy port.
- `proxy_type` (String) `NoProxy`, `DefaultProxy`, `Http` or `Socks5`.
- `proxy_username` (String) Proxy username.
- `ttl` (Number) TTL in seconds. Defaults to the server's default record TTL. All records of one type at the same name form an RRset and share a single TTL, so give them the same value.

### Read-Only

- `fqdn` (String) Fully qualified domain name of the record.
- `id` (String) Record identifier and import ID: `<zone>/<name>/<protocol> <forwarder>`.
