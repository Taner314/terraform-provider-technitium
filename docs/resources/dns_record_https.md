# technitium_dns_record_https (Resource)

Manages an HTTPS (HTTPS service binding) record.

Records are matched by zone, name and `priority`, `target_name`.

## Example Usage

```terraform
resource "technitium_dns_record_https" "apex" {
  zone           = "example.com"
  name           = "@"
  priority       = 1
  target_name    = "."
  params         = { alpn = "h2,h3" }
  auto_ipv4_hint = true
}
```

## Schema

### Required

- `name` (String) Record name relative to the zone; `@` for the zone apex.
- `priority` (Number) SvcPriority; 0 makes it an alias record.
- `target_name` (String) Target name; `.` means the owner name.
- `zone` (String) Authoritative zone the record belongs to.

### Optional

- `auto_ipv4_hint` (Boolean) Fill `ipv4hint` automatically from the target's A records.
- `auto_ipv6_hint` (Boolean) Fill `ipv6hint` automatically from the target's AAAA records.
- `comments` (String) Free-form comments stored with the record.
- `disabled` (Boolean) Whether the record is disabled (kept but not served).
- `expiry_ttl` (Number) Seconds after the last modification at which the server deletes the record; 0 disables expiry.
- `params` (Map of String) SvcParams, e.g. `{ alpn = "h2,h3", port = "8443" }`. Hints filled by `auto_ipv4_hint`/`auto_ipv6_hint` are not tracked here.
- `ttl` (Number) TTL in seconds. Defaults to the server's default record TTL. All records of one type at the same name form an RRset and share a single TTL, so give them the same value.

### Read-Only

- `fqdn` (String) Fully qualified domain name of the record.
- `id` (String) Record identifier and import ID: `<zone>/<name>/<priority> <target_name>`.
