# technitium_dns_record_naptr (Resource)

Manages a NAPTR (naming authority pointer) record.

Records are matched by zone, name and `order`, `preference`, `flags`, `services`, `regexp`, `replacement`.

## Example Usage

```terraform
resource "technitium_dns_record_naptr" "sip" {
  zone        = "example.com"
  name        = "@"
  order       = 100
  preference  = 10
  flags       = "U"
  services    = "E2U+sip"
  regexp      = "!^.*$!sip:info@example.com!"
  replacement = "."
}
```

### Required

- `flags` (String) Flags, e.g. `U`.
- `name` (String) Record name relative to the zone; `@` for the zone apex.
- `order` (Number) Order in which records are processed.
- `preference` (Number) Preference among records with the same order.
- `regexp` (String) Substitution expression.
- `replacement` (String) Replacement domain name, `.` for none.
- `services` (String) Services, e.g. `E2U+sip`.
- `zone` (String) Authoritative zone the record belongs to.

### Optional

- `comments` (String) Free-form comments stored with the record.
- `disabled` (Boolean) Whether the record is disabled (kept but not served).
- `expiry_ttl` (Number) Seconds after the last modification at which the server deletes the record; 0 disables expiry.
- `ttl` (Number) TTL in seconds. Defaults to the server's default record TTL. All records of one type at the same name form an RRset and share a single TTL, so give them the same value.

### Read-Only

- `fqdn` (String) Fully qualified domain name of the record.
- `id` (String) Record identifier and import ID: `<zone>/<name>/<order> <preference> <flags> <services> <regexp> <replacement>`.
