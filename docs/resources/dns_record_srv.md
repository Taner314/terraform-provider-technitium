# technitium_dns_record_srv (Resource)

Manages an SRV (service locator) record. `name` is the service label, e.g. `_sip._tcp`.

Records are matched by zone, name and `priority`, `weight`, `port`, `target`.

## Example Usage

```terraform
resource "technitium_dns_record_srv" "sip" {
  zone     = "example.com"
  name     = "_sip._tcp"
  priority = 10
  weight   = 5
  port     = 5060
  target   = "sip.example.com"
}
```

## Schema

### Required

- `name` (String) Record name relative to the zone; `@` for the zone apex.
- `port` (Number) Service port.
- `priority` (Number) Priority; lower values are tried first.
- `target` (String) Target host name.
- `weight` (Number) Relative weight among records with the same priority.
- `zone` (String) Authoritative zone the record belongs to.

### Optional

- `comments` (String) Free-form comments stored with the record.
- `disabled` (Boolean) Whether the record is disabled (kept but not served).
- `expiry_ttl` (Number) Seconds after the last modification at which the server deletes the record; 0 disables expiry.
- `ttl` (Number) TTL in seconds. Defaults to the server's default record TTL. All records of one type at the same name form an RRset and share a single TTL, so give them the same value.

### Read-Only

- `fqdn` (String) Fully qualified domain name of the record.
- `id` (String) Record identifier and import ID: `<zone>/<name>/<priority> <weight> <port> <target>`.

# <zone>/<name>/<priority> <weight> <port> <target>
