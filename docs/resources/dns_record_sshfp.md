# technitium_dns_record_sshfp (Resource)

Manages an SSHFP (SSH fingerprint) record.

Records are matched by zone, name and `algorithm`, `fingerprint_type`, `fingerprint`.

## Example Usage

```terraform
# Values from `ssh-keygen -r server1.example.com`.
resource "technitium_dns_record_sshfp" "host" {
  zone             = "example.com"
  name             = "server1"
  algorithm        = "Ed25519"
  fingerprint_type = "SHA256"
  fingerprint      = "aabbccddeeff00112233445566778899aabbccddeeff00112233445566778899"
}
```

## Schema

### Required

- `algorithm` (String) Key algorithm: `RSA`, `DSA`, `ECDSA`, `Ed25519` or `Ed448`.
- `fingerprint` (String) Fingerprint as a hex string.
- `fingerprint_type` (String) Fingerprint type: `SHA1` or `SHA256`.
- `name` (String) Record name relative to the zone; `@` for the zone apex.
- `zone` (String) Authoritative zone the record belongs to.

### Optional

- `comments` (String) Free-form comments stored with the record.
- `disabled` (Boolean) Whether the record is disabled (kept but not served).
- `expiry_ttl` (Number) Seconds after the last modification at which the server deletes the record; 0 disables expiry.
- `ttl` (Number) TTL in seconds. Defaults to the server's default record TTL. All records of one type at the same name form an RRset and share a single TTL, so give them the same value.

### Read-Only

- `fqdn` (String) Fully qualified domain name of the record.
- `id` (String) Record identifier and import ID: `<zone>/<name>/<algorithm> <fingerprint_type> <fingerprint>`.
