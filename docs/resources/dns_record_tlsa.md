# technitium_dns_record_tlsa (Resource)

Manages a TLSA (DANE) record. `name` is e.g. `_443._tcp`.

Records are matched by zone, name and `certificate_usage`, `selector`, `matching_type`, `certificate_association_data`.

## Example Usage

```terraform
resource "technitium_dns_record_tlsa" "smtp" {
  zone                         = "example.com"
  name                         = "_25._tcp.mail"
  certificate_usage            = "DANE-EE"
  selector                     = "SPKI"
  matching_type                = "SHA2-256"
  certificate_association_data = "aabbccddeeff00112233445566778899aabbccddeeff00112233445566778899"
}
```

## Schema

### Required

- `certificate_association_data` (String) Certificate association data as a hex string.
- `certificate_usage` (String) `PKIX-TA`, `PKIX-EE`, `DANE-TA` or `DANE-EE`.
- `matching_type` (String) `Full`, `SHA2-256` or `SHA2-512`.
- `name` (String) Record name relative to the zone; `@` for the zone apex.
- `selector` (String) `Cert` or `SPKI`.
- `zone` (String) Authoritative zone the record belongs to.

### Optional

- `comments` (String) Free-form comments stored with the record.
- `disabled` (Boolean) Whether the record is disabled (kept but not served).
- `expiry_ttl` (Number) Seconds after the last modification at which the server deletes the record; 0 disables expiry.
- `ttl` (Number) TTL in seconds. Defaults to the server's default record TTL. All records of one type at the same name form an RRset and share a single TTL, so give them the same value.

### Read-Only

- `fqdn` (String) Fully qualified domain name of the record.
- `id` (String) Record identifier and import ID: `<zone>/<name>/<certificate_usage> <selector> <matching_type> <certificate_association_data>`.
