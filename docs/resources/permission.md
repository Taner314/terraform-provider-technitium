# technitium_permission (Resource)

Grants a user or group access to a server section. Only this entry is managed; others in the section are left alone.

## Example Usage

```terraform
resource "technitium_group" "dns_ops" {
  name        = "dns-ops"
  description = "Can edit zones"
}

resource "technitium_permission" "dns_ops_zones" {
  section    = "Zones"
  group      = technitium_group.dns_ops.name
  can_view   = true
  can_modify = true
}
```
