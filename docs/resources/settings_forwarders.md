# technitium_settings_forwarders (Resource)

Manages server-wide forwarders. With no forwarders the server resolves recursively.

This is a singleton: declare it once. Attributes left unset follow the server's current value. Destroying the resource only removes it from state; server settings are not reset.

## Example Usage

```terraform
resource "technitium_settings_forwarders" "this" {
  forwarders = ["dns.quad9.net (9.9.9.9:853)", "cloudflare-dns.com (1.1.1.1:853)"]
  protocol   = "Tls"
}
```

## Schema

### Optional

- `concurrency` (Number) Forwarders queried concurrently.
- `concurrent_forwarding` (Boolean) Query forwarders concurrently.
- `forwarders` (List of String) Forwarder addresses, e.g. `1.1.1.1`, `dns.quad9.net (9.9.9.9:853)`, `https://cloudflare-dns.com/dns-query`. Default ports may be omitted.
- `protocol` (String) `Udp`, `Tcp`, `Tls`, `Https` or `Quic`. Requires `forwarders`; with no forwarders the server resets it to `Udp`.
- `retries` (Number) Retries per forwarder.
- `timeout` (Number) Timeout per query in milliseconds.

### Read-Only

- `id` (String) Always `settings`.
