# technitium_settings_proxy (Resource)

Manages the outbound proxy used for recursion, forwarding and block list downloads.

This is a singleton: declare it once. Attributes left unset follow the server's current value. Destroying the resource only removes it from state; server settings are not reset.

## Example Usage

```terraform
# Outbound proxy for recursion, forwarding, block lists and app downloads.
resource "technitium_settings_proxy" "this" {
  type    = "Socks5"
  address = "10.0.0.5"
  port    = 1080
  bypass  = ["127.0.0.0/8", "10.0.0.0/8", "192.168.0.0/16", "localhost"]
}
```
