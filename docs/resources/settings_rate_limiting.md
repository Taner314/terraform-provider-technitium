# technitium_settings_rate_limiting (Resource)

Manages per-subnet query rate limits (queries per minute).

This is a singleton: declare it once. Attributes left unset follow the server's current value. Destroying the resource only removes it from state; server settings are not reset.

## Example Usage

```terraform
resource "technitium_settings_rate_limiting" "this" {
  ipv4_prefix_limits = [
    { prefix = 32, udp_limit = 600, tcp_limit = 600 },
    { prefix = 24, udp_limit = 6000, tcp_limit = 6000 },
  ]
  bypass_list = ["192.168.0.0/16"]
}
```
