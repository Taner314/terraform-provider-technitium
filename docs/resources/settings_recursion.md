# technitium_settings_recursion (Resource)

Manages recursive resolution.

This is a singleton: declare it once. Attributes left unset follow the server's current value. Destroying the resource only removes it from state; server settings are not reset.

## Example Usage

```terraform
resource "technitium_settings_recursion" "this" {
  recursion   = "UseSpecifiedNetworkACL"
  network_acl = ["192.168.0.0/16", "10.0.0.0/8"]
}
```

## Schema

### Optional

- `locally_served_dns_zones` (Boolean) Answer RFC 6303 locally-served zones locally.
- `network_acl` (List of String) Ordered ACL when `recursion` is `UseSpecifiedNetworkACL`; prefix `!` to deny.
- `qname_minimization` (Boolean) Use QNAME minimisation.
- `randomize_name` (Boolean) Randomise query name case (0x20).
- `recursion` (String) `Deny`, `Allow`, `AllowOnlyForPrivateNetworks` or `UseSpecifiedNetworkACL`.
- `resolver_concurrency` (Number) Name servers queried concurrently.
- `resolver_max_stack_count` (Number) Maximum recursion depth.
- `resolver_retries` (Number) Retries per name server.
- `resolver_timeout` (Number) Timeout per query in milliseconds.

### Read-Only

- `id` (String) Always `settings`.
