# technitium_settings_web_service (Resource)

Manages the web console/API listener. Changing ports or TLS can cut off the provider's own connection; update the provider `host` accordingly.

This is a singleton: declare it once. Attributes left unset follow the server's current value. Destroying the resource only removes it from state; server settings are not reset.

## Example Usage

```terraform
# Changing ports or TLS changes how the provider must reach the server.
resource "technitium_settings_web_service" "this" {
  enable_tls              = true
  tls_port                = 53443
  http_to_tls_redirect    = true
  tls_certificate_path    = "/etc/dns/certs/dns.example.com.pfx"
  reverse_proxy_addresses = ["10.0.0.2"]
}
```
