# technitium_sso (Resource)

Manages OpenID Connect single sign-on for the web console (Technitium 15+). Singleton; unset attributes follow the server. Changes may restart the web service; the provider waits for it to return.

## Example Usage

```terraform
resource "technitium_sso" "this" {
  enabled           = true
  authority         = "https://auth.example.com/application/o/technitium/"
  client_id         = "technitium"
  client_secret     = var.oidc_client_secret
  additional_scopes = ["email", "groups"]
  group_map = [
    { remote_group = "dns-admins", local_group = "DNS Administrators" },
  ]
}
```

## Schema

### Optional

- `additional_scopes` (List of String) Scopes requested besides `openid` and `profile` (always requested), e.g. `["email", "groups"]`.
- `allow_signup` (Boolean) Create accounts for new SSO users on first sign-in.
- `allow_signup_only_for_mapped_users` (Boolean) Only sign up users in at least one mapped remote group.
- `authority` (String) OIDC authority (issuer) URL, e.g. `https://auth.example.com/application/o/technitium/`.
- `client_id` (String) OIDC client ID.
- `client_secret` (String, Sensitive) OIDC client secret. Not readable from the server, so outside changes are not detected.
- `enabled` (Boolean) Enable SSO.
- `group_map` (List of Object) Remote-to-local group mapping: objects with `remote_group` and `local_group`. (see [below for nested schema](#nestedatt--group_map))
- `metadata_address` (String) Discovery URL, only if the provider doesn't use the standard one.
