# technitium_user (Resource)

Manages a local user account. Group membership is managed here, not on `technitium_group`.

## Example Usage

```terraform
resource "technitium_group" "dns_ops" {
  name = "dns-ops"
}

resource "technitium_user" "external_dns" {
  username     = "external-dns"
  password     = var.external_dns_password
  display_name = "external-dns (k8s)"
  groups       = [technitium_group.dns_ops.name]
}
```

## Schema

### Required

- `password` (String, Sensitive) Password. The server cannot return it, so changes made outside Terraform are not detected; after an import the first apply resets it to this value.
- `username` (String) Username. Changing it renames the account in place.

### Optional

- `disabled` (Boolean) Disable the account; this also ends its sessions.
- `display_name` (String) Display name. Defaults to the username.
- `groups` (Set of String) Groups the user belongs to. `Everyone` is implicit and cannot be listed.
- `session_timeout_seconds` (Number) Session timeout in seconds. Defaults to the server's value (1800).

### Read-Only

- `id` (String) Username.
- `totp_enabled` (Boolean) Whether the user has enabled two-factor authentication.

```shell
terraform import technitium_user.external_dns external-dns
```
